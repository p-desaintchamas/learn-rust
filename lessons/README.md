# Lessons

One file per day: `day-01.md` … `day-30.md`. Each is a self-contained 30-minute
lesson with four parts:

1. **▶ Watch** (~5 min) — a short video.
2. **📖 Read** (~8–10 min) — a focused slice of the Rust Book (or a crate's docs).
3. **⌨️ Practice** (≥10 min) — hands-on, in the [Playground](https://play.rust-lang.org/)
   or Rustlings.
4. **🔨 Build** — the concrete change you make to the `streak` project that day.

Each lesson ends with a **✅ Checkpoint** — what you should be able to do before
moving on. If a checkpoint feels shaky, that's the signal to redo the practice
rather than push ahead. Slow is better than not at all.

Week 1 (days 1–5) is written out in full here so you can start immediately.
The remaining lessons are generated each weekday morning from
[`../PLAN.md`](../PLAN.md) — but you can always read ahead in the plan and go
faster.
